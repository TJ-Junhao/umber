Before using this skill, compare `metadata.umber-version` above with `umber.__version__`. If they differ, ask the user to reinstall with `python -m umber skill install --agent NAME`, choosing `claude-code`, `codex`, `cursor` or `pi` for NAME and adding `--user` if this skill was installed in the home directory.

The [generated API reference](references/api.md) lists every public export, typed signatures and docstring examples. Use it for the API supported by this version of umber.

Installing for both Claude Code and Cursor gives Cursor two identical copies, because Cursor also reads `.claude/skills/`.
